# Archive — Documentación Histórica

Esta carpeta contiene documentación histórica, reportes de auditoría y notas de reparación.

- `AUDIT_PLAN.md` — Plan de auditoría inicial
- `AUDIT_REPORT.md` — Reporte completo
- `AUDITORIA_*.md` — Auditorías temáticas

### history/

Registro de reparaciones, optimizaciones y cambios:
- `REPARACIONES_*.md` — Fixes implementados
- `OPTIMIZACIONES_*.md` — Mejoras de performance
- `ACTUALIZACIONES_*.md` — Cambios de versiones
- `RESUMEN_*.md` — Resúmenes de sesiones

### legacy/

- `README_DEMO.md` — Demo inicial
- `README_PROVEEDORES_REMOVED.md` — Modulo removido

- `LOGIN_CREDENTIALS.md` — Accesos de prueba
