# Módulo Brief

Resumen global del negocio (límite por cuenta, no por producto).

## Descripción

Brief sintetiza todos los análisis anteriores en un documento ejecutivo. Límite: 1 por cuenta (plan-dependent).

## Input

Compilado automáticamente desde:
- Todos los productos del usuario
- Todos los análisis completados

## Output

json
{
 "resumen_ejecutivo": "...",
 "fortalezas": [...],
 "debilidades": [...],
 "oportunidades": [...],
 "amenazas": [...],
 "próximos_pasos": [...]
}
